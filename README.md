# Scratch to Python

Lessons for moving from Scratch to Python, one course per folder.

| Course | Folder | What you build |
| --- | --- | --- |
| Slingshot Physics | [slingshot-physics/](slingshot-physics/README.md) | A Scratch-style slingshot game rebuilt in Python with pygame |

## How to use these lessons

1. Click **Use this template** at the top of this page to make your own private copy.
2. Clone your copy into VS Code (**File → Clone Repository**).
3. Work through the lessons in order, and commit your work as you go.

You don't need a GitHub account to read these lessons. You only need one to make your own copy.
